The widget text scale

A widget is read from about twice the distance of a document, so its type is roughly double (§8.3): --t-widget-text is 20/1.35 and the hand-written cells use it as .noo-bento__text. No registered component renders that size — Text size='small' is the document’s 15 and visibly smaller. Status, cases, projects and both glass cells show it. Below: the Status widget’s last row, five ways.

Five directions

The bottom row is the one that changes; the rest is the widget as the document already renders it (with F1 A applied to the heads).

A

Text gains size='widget'

recommended

A fourth step on the one prose component: lead · body · small · widget, where widget is --t-widget-text. The registry’s enum grows by one; the inspector’s Segmented shows four options, which is its limit.

fits one enum value · Text stays the only prose · F5 inherits it

The prose component already carries the scale; the widget’s step was simply missing from it. Nothing new to register, nothing new to name, and a list in a cell (board F5) gets its size from the same prop. Cost: an author can put widget-size text in a page panel — which is also what a Heading can do, and the inspector shows the size live.

B

The cell sets the scale — no prop at all

Context, not a value: inside .noo-bento__cell, Text’s sizes remap (small → widget-text, body → widget-title). The document says size: small and the cell makes it 20.

fits CSS only · the same node reads right in a cell and in a panel

Elegant, and invisible: the inspector says small and the canvas shows 20, so the author cannot tell what they are choosing. A remap is also a second scale nobody can read off the tokens. Rejected for the same reason the tiers were retired — a trick standing in for a design.

C

CellHead gains a line

Widget prose only ever sits under a head, so CellHead takes an optional line (text, ≤ 120) at the widget scale under its title.

fits one prop on one composite · no free-standing text in a cell

True for the Status row — but the through-line row has a label, then chips, and the Projects row has a label and a line with no title. A line that can only follow a title makes those two cells unauthorable again, which is how the ten new components came to exist (§9.3 ⑨).

D

A BentoText component

A slot-only component for a widget’s prose: markdown at --t-widget-text, nothing else. The registry grows by one, kind slot.

fits one new entry · names the thing exactly

Names exactly what it is, and that is also the problem: two prose components with one prop between them. The palette gets longer for a size, and every future scale step would ask for its own component.

E

Keep small — and quieten the hand-written widgets

Leave Text as it is and move content/sections.tsx to size='small', so the two match by making the widgets quieter.

fits no package change · the live portfolio changes

Matches the document to the code by changing the design, not the library, and it is the design that was measured: 20 was chosen so a line reads at map zoom. It also touches what a visitor sees, which steps 1–6 promised not to.
