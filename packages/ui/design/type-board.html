Phosphate Solid, and eleven faces in its spirit

Body stays Hanken Grotesk — that's decided and every paragraph here is set in it. This is only the display face: the wordmark, headings, the big type. Each card shows the caps wordmark with the blob, a headline, the lowercase, and how it sits next to Hanken.

Grouped by distance from Phosphate: its closest free cousins first, then rounded faces with real weight ranges, then two contrarian options. Single-weight faces can only make hierarchy with size — that's flagged where it applies.

LicencePhosphate ships with macOS (Solid and Inline) but not with the web. Using it on the site means a webfont licence from its foundry (Red Rooster / International TypeFounders) — a one-off fee, entirely doable — or picking the closest free sibling below. It renders on this page only because you're on a Mac; checking whether it's installed…
