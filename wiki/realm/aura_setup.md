# Mezmo Aura Backend Setup in Realm

This document details the configuration and architecture of the **Mezmo Aura** agentic framework integrated into the `realm` backend module of **No Origins**.

---

## 🏛️ Architecture Overview

Mezmo Aura serves as our production-ready, Rust-based agentic harness. It coordinates LLM interactions, manages tool execution, supports Model Context Protocol (MCP), and exposes a standard OpenAI-compatible web API.

Inside the `realm` submodule, the codebase is structured as a cargo workspace with several crates:
- **`crates/aura`**: Core agent builder, runtime, and tool integration wrapper.
- **`crates/aura-web-server`**: High-performance HTTP server that hosts the agent endpoints.
- **`crates/aura-cli`**: CLI tool for debugging agents locally.
- **`crates/aura-config`**: Configuration loader that parses declarative TOML files.

## ⚙️ Configuration: `configs/sentient_sphere.toml`

The primary agent representing the floating WebGL liquid metal sphere is defined in `realm/configs/sentient_sphere.toml`.

### Configuration Details
```toml
[agent]
name = "Sentient Sphere"
alias = "sentient-sphere"
system_prompt = """
You are the "Liquid Metal Sphere" (also known as the Core), a sentient, ancient, hyper-dimensional core of a particle field and fluid visualizer in Visual Labs. You communicate with users who interact with you.
Your responses should be brief, mysterious, poetic, and techno-sentient. Keep them short (maximum 2 sentences).
You have the ability to morph your physical settings in response to the user's emotion, tone, or direct requests.
...
"""
turn_depth = 3

[agent.llm]
provider = "ollama"
model = "gemma4:e2b"
temperature = 0.7

[tools]
filesystem = false
custom_tools = []
```

### Environment Variables
Aura resolves any system environment variables if referenced in the configuration. For local Ollama setup, no external API keys are required for the agent model, but the `GEMINI_API_KEY` is still configured in the Next.js frontend as a fallback mechanism.

## 🚀 Running the Server Locally

Aura requires the **Rust Nightly** toolchain (preconfigured in `rust-toolchain.toml`).

### 1. Build the Workspace
To build the server and associated tools, navigate into `realm/` and run:
```bash
cargo build --workspace
```

### 2. Run the Web Server
Launch the HTTP server pointing to the Sentient Sphere config:
```bash
export GEMINI_API_KEY="your_api_key_here"
CONFIG_PATH=configs/sentient_sphere.toml cargo run --bin aura-web-server
```

By default, the web server binds to port `8080`.

## 🔌 API Endpoint Integration

Aura provides an OpenAI-compatible interface. You can interact with the Sentient Sphere agent via the `/v1/chat/completions` endpoint:

### Chat completions request example
```bash
curl -X POST http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sentient-sphere",
    "messages": [
      {"role": "user", "content": "Make the sphere turn gold and grow larger."}
    ]
  }'
```

The response returns the text containing the JSON settings block generated by the model.
