# no-origins: for Codex and every other agent

Read `CLAUDE.md` in this directory before anything else. It is the one source of this repository's rules, and all of
it applies to you; this file only points there.

- In an app, read the app's `CLAUDE.md` too: its `AGENTS.md` only points there and carries the Next.js rules
  `next dev` writes.
- `packages/ui/CLAUDE.md` holds the design system's own rules.
- Your skills are in `.agents/skills/`; `.claude/skills/` holds the same skills for Claude. Keep the two copies identical.
